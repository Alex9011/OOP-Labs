# Lab3 — Розробка інтерфейсу користувача

Python 3.10+ з Tkinter. Сторонні пакети для запуску не потрібні.

## Запуск
Відкрийте run.bat або виконайте `python Lab3.py`.
Перевірка Tkinter: `python -m tkinter`. На Ubuntu потрібен python3-tk.

## Керування
Оберіть фігуру в меню «Об’єкти» або кнопкою з іконкою.
Наведіть курсор на кнопку й зачекайте 0,5 с для підказки.
Крапка — клацання; решта — перетягування лівою кнопкою.
Прямокутник вводиться від центру до кута, еліпс — за двома кутами.
Esc скасовує поточну фігуру. «Файл → Очистити» очищує модель.

## Варіант
Ж = 16 + 1 = 17; 117 місць; червоний суцільний гумовий слід.
Прямокутник сірий із чорним контуром; еліпс без заповнення.
Поточний інструмент відображається в заголовку, меню та панелі.
Список фіксованої довжини — аналог статичного масиву Shape* у Python.
OnNotify — метод ToolTip для події наведення, не нативне повідомлення Win32.

## Перевірка і збирання
`python -m unittest -v` — тести моделі без графічного дисплея.
На Windows запустіть build_exe.bat; потрібен інтернет для PyInstaller.
Результат — dist/Lab3.exe. Скрипт включає PNG-іконки до exe.
Windows exe та графічний запуск у середовищі підготовки не перевірено.
До звіту слід додати власні скриншоти запущеної програми.
