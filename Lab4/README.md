# Lab4 — варіант 16

Вдосконалення структури коду графічного редактора об’єктів.
Python 3.10+ та Tkinter. Сторонні пакети для запуску не потрібні.


## Керування

Меню «Об’єкти» і панель іконок вибирають одну з шести фігур.
Наведіть курсор на іконку на 0,5 с — з’явиться підказка.
Крапка — клацання. Решта — перетягування лівою кнопкою миші.
Прямокутник: від центру до кута, сіре заповнення.
Еліпс: два протилежні кути, без заповнення.
Лінія з кружечками: вибрані точки задають центри кружечків радіуса 7.
Куб: діагональ передньої грані; довжина сторони — менший із розмірів
протягування. Задня грань зміщена праворуч і вгору на 30% сторони.
Частини фігури за межами полотна відсікаються Canvas.
Esc скасовує незавершене введення; «Файл → Очистити» очищує полотно.
Фігури зберігаються тільки в пам’яті до закриття програми.

## Відповідність завданню

- Номер у журналі 16 — динамічний `MyEditor()` у `Application.__init__`.
- Закриття через меню або хрестик викликає `Application.close()`:
  скасування таймерів підказок, очищення MyEditor, видалення посилання
  власника й знищення вікна. `main()` має також блок finally.
- У Python пам’яттю керує середовище виконання; `close()` звільняє
  ресурси явно, а `self.editor = None` прибирає посилання власника.
- Кольори та геометрія старих фігур збережені з Lab3 (там параметри
  обчислювалися для 17). Для Lab4 номер 16 визначає спосіб створення
  редактора; кольори заново за формулами Lab2 не обчислюються.
- Місткість 117 залишена з Lab3: нова умова її не перевизначає.
- Preview кожної фігури — червоний пунктир (4, 3), без заповнення.
- Нові класи мають множинне успадкування. Show явно викликає методи
  LineShape, EllipseShape та RectShape на тому самому об’єкті self.
- У tools.py один реєстр TOOLS для фабрик, меню, Toolbar та підказок.
- Файли PNG в assets включаються до exe скриптом PyInstaller.

## Тести та виконуваний файл

`python -m unittest -v` — усі тести. Без графічного дисплея GUI-тести
будуть skipped; модель перевіряється незалежно від вікна.
Під час підготовки пройдено 11 тестів, включно з GUI.
Повний результат — TEST_RESULTS.txt.

Для Windows exe запустіть build_exe.bat. Потрібен інтернет для встановлення
PyInstaller. Результат: dist/Lab4.exe. Windows exe в цьому Linux-середовищі
не збирався й не перевірявся; готовий exe до архіву не входить.

## Додавання фігури

1. Створіть підклас Shape та реалізуйте Show(canvas, preview=False).
2. Додайте PNG-іконку у assets.
3. Додайте Tool(...) до TOOLS у tools.py з унікальним key.

Після перезапуску пункт меню, кнопка й підказка створяться автоматично.
Змінювати обробники миші та MyEditor для цього не потрібно.
