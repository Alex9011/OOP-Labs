# Захист лабораторної роботи №5

**Що показати.** Відкрити таблицю через «Вигляд», намалювати фігуру за відкритої таблиці й показати новий рядок. Вибрати його, показати рамку та видалити фігуру. Зберегти CSV, очистити редактор і завантажити файл. Завершити роботу з відкритою таблицею.

**Що змінилося після Lab4.** У Lab4 головне вікно створювало свій MyEditor. У Lab5 воно одержує спільний екземпляр через `MyEditor.instance()`. До того ж самого редактора під’єднано немодальну таблицю та імпорт і експорт CSV.

| Місце в коді | Пояснення |
| --- | --- |
| `editor.py`, 8–25 | Атрибут класу зберігає екземпляр. `instance()` створює його один раз. Ключ створення дозволяє викликати конструктор із `instance()`. |
| `Lab5.py`, 38–41 | Передаємо методи головного вікна в MyTable як callbacks. Пункт меню відкриває та закриває таблицю. |
| `my_table.py`, 21–48 | Toplevel і Treeview працюють у тому самому циклі подій, що й полотно. Обидва вікна доступні одночасно. |
| `my_table.py`, 65–86 | Таблиця отримує індекс вибраного рядка й викликає переданий метод. Усі імпорти цього модуля належать Tkinter. |
| `Lab5.py`, 114–129 | Application перетворює фігури на рядки. Вибір викликає перемальовування. Видалення змінює колекцію та оновлює обидва вікна. |
| `editor.py`, 101–117 | Спільний виклик `Show(canvas)` для різних фігур демонструє поліморфізм. Після нього для вибраної фігури додається рамка. |
| `shape_csv.py`, 13–52 | Записуємо тип і чотири координати. Під час читання ключ типу визначає клас, а координати передаються його конструктору. |
| `Lab5.py`, 131–146 | Завантаження замінює сцену після успішної перевірки всіх записів. Після заміни оновлюються полотно й таблиця. |
| `Lab5.py`, 177–187 | На виході закриваємо таблицю, прибираємо таймери підказок і звільняємо Singleton. |
