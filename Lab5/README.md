# Лабораторна робота №5 — варіант 16

Графічний редактор Python/Tkinter на основі Lab4. Він зберігає шість фігур, їхні кольори, пунктирний гумовий слід і Toolbar з підказками.

## Запуск

- Windows із Python 3.10+ і Tkinter: відкрийте `run.bat`.
- Із термінала: `python Lab5.py` або `python Lab5.pyz`. Архів `Lab5.pyz` містить програму й іконки та запускається з установленим Python/Tkinter.
- Для окремого Windows EXE запустіть `build_exe.bat` на Windows. Потрібен доступ для встановлення PyInstaller. Результат збірки — `dist/Lab5.exe`.

## Демонстрація

1. Виберіть **Вигляд → Відкрити таблицю**. Малюйте мишею в головному вікні за відкритої таблиці. Кожна завершена фігура одразу з’являється в таблиці.
2. Виберіть рядок. Навколо відповідної фігури з’явиться бірюзова рамка. Натисніть **Видалити вибрану фігуру** або клавішу Delete у таблиці.
3. Збережіть сцену командою **Файл → Зберегти CSV…**. Потім відкрийте її через **Файл → Відкрити CSV…**. Для першої демонстрації можна використати `example_shapes.csv`.
4. Закрийте таблицю з меню або хрестиком і відкрийте знову. Вихід із редактора закриває обидва вікна.

CSV має заголовок `type,x1,y1,x2,y2` і кодування UTF‑8. Типи — `point`, `line`, `rectangle`, `ellipse`, `circles`, `cube`. У крапки обидві пари координат збігаються. У прямокутника перша пара задає центр, друга — кут. Завантаження замінює поточну сцену після перевірки всього файла. Місткість — 117 фігур.

## Файли

- `Lab5.py` — головне вікно, меню, події та синхронізація двох вікон.
- `editor.py` — класичний Singleton `MyEditor`, колекція й малювання.
- `my_table.py` — немодальна таблиця `MyTable` і callbacks. Імпортує лише Tkinter.
- `shape_csv.py` — збереження й завантаження. Класи фігур вибираються через реєстр.
- `shapes.py`, `tools.py`, `toolbar.py` — ієрархія фігур, реєстр інструментів і панель із Lab4.

Тести запускаються командою `python -m unittest -v`. Для інтеграційних тестів потрібен графічний дисплей.
