# Lab2 — графічний редактор, варіант 16

## Запуск у Windows
1. Розпакуйте весь архів в одну папку.
2. Потрібен Python 3 із Tkinter (компонент Tcl/Tk у встановлювачі Python).
3. Запустіть run.bat або виконайте `py -3 Lab2.py` у цій папці.
Сторонні бібліотеки для роботи редактора не потрібні.

## Керування
Об’єкти → Крапка / Лінія / Прямокутник / Еліпс.
Крапка: клацання. Інші фігури: затиснути ліву кнопку, перетягнути, відпустити.
Прямокутник: від одного кута до протилежного. Еліпс: від центру до кута охоплюючого прямокутника.
Під час перетягування видно чорний суцільний контур. Esc скасовує поточну фігуру.
Файл → Очистити видаляє всі об’єкти. Максимум 116 об’єктів.
Білий еліпс перекриває фігури під ним: це заповнення, а не прозорість.

## Варіант
16 mod 3 = 1: фіксований масив на 116 посилань.
16 mod 4 = 0: чорний суцільний гумовий слід.
16 mod 2 = 0: прямокутник за кутами; еліпс від центру; позначка в меню.
16 mod 5 = 1: прямокутник кольоровий, еліпс білий.
16 mod 6 = 4: прямокутник помаранчевий.

## Відмінності Python від C++ / WinAPI
Python не має синтаксису Shape* та статичних масивів C++. Використано `[None] * 116`;
довжина списку ніколи не змінюється, об'єкти записуються за індексом. Елементи зберігають посилання.
Tkinter `postcommand` викликає метод `OnInitMenuPopup` перед відкриттям меню.
Це адаптація завдання на Python, а не буквальне використання WM_INITMENUPOPUP.
Якщо викладач вимагає саме C++/WinAPI або масив Shape*, погодьте цю адаптацію.

## Файли
Lab2.py — вікно, меню, події миші. shapes.py — абстрактний Shape та чотири нащадки.
editor.py — зберігання та поліморфний виклик show. REPORT.md — матеріал звіту з повним кодом.
class_diagram.mmd — діаграма успадкування. test_model.py — перевірки моделі.

## Виконуваний файл
Запустіть build_exe.bat у Windows. Він встановить PyInstaller (потрібен інтернет),
зібере dist/Lab2.exe. На комп’ютері користувача готового EXE Python не потрібен.
EXE в цьому архіві відсутній: Windows-збірку тут не виконано.

## Перевірка перед здачею
Намалюйте всі 4 типи; перевірте прямокутник у різних напрямках та симетрію еліпса від центра.
Перевірте позначку в меню, Esc, очищення та відновлення вікна після згортання.
Для звіту зробіть справжні скріншоти: полотно з 4 фігурами; меню з позначкою;
контур під час перетягування (зручно записати екран і взяти кадр).
Автоматичні перевірки: `py -3 -m unittest -v`.
